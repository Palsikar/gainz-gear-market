# 💪 GainzGear Market

**GainzGear Market** is a modern, responsive e-commerce web app focused on premium fitness supplements. Built with React, Tailwind CSS, and modern frontend tooling, it offers a seamless shopping experience tailored for gym enthusiasts and athletes.

---

## 🚀 Live Demo

👉 [GainzGear Market Demo](https://gainz-gear-market.vercel.app)

---

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS, Bootstrap  
- **Routing:** React Router  
- **Authentication:** Firebase 
- **Deployment:** Vercel
